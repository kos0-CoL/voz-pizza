      5 Evaluación del orquestador

      Corre el set de data/pedidos-prueba.json: ambigüedades, ítems inexistentes, cantidades habladas y stock. El mismo texto pasa primero por el simulador y después por el modelo real, y se compara estado, total, líneas y secuencia de skills.

      Todavía no corriste el set.

      La clave de API queda en este navegador y se envía directo a Google. El catálogo vive en data/menu.json y el set de prueba en data/pedidos-prueba.json.

      Configuración del orquestador

      Necesitás una API key de Google AI Studio (tiene free tier). Se guarda solo en localStorage de este navegador y no pasa por ningún servidor nuestro. En el free tier Google puede usar los prompts para mejorar sus productos.

      Creá una clave en aistudio.google.com/apikey.
